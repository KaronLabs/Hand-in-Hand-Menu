기준 커밋: aac1e1c36706d4c8e90b648a6335a09e5b273b52. 요청에 따라 본인이 직접 점검합니다. 기존 독립 검토와 구분합니다. 사이트 공개 범위·주소·메뉴 원문은 유지합니다.

전체 테스트 기존 기준은 105개 통과입니다. 수치 커버리지는 core, renderer, client로 한정하고 원문 사실 정확성·CSS·Sites 내부·라이브러리·실물 기기까지 확장해 주장하지 않습니다. 미검증 사항을 통과로 표기하지 않습니다.

## 진행 순서

1. 원문과 전 코드/테스트/산출물 읽기, 실제 실패 재현.
2. 결함별 RED 테스트 → 최소 수정 → GREEN, 이후 필요한 정리.
3. 전체 회귀/커버리지/빌드, 모바일 브라우저, QR/배포물 검증.
4. 같은 사이트에 게시 후 결과/미확인 사항을 제출 전 기록으로 확정.

## 최초 재현

- 위스키 첫 행을 single/1원으로 변경해도 validateMenu가 빈 오류 목록 반환.
- 카쵸 에 페페 raw 22,000을 둔 채 amountKrw 999로 변경해도 통과.
- 고르곤졸라 옵션이 화면에 있지만 검색 결과 0개.
- 네그로니 검색 결과 1개인데 분류 수는 7가지 유지.
- ingredientsKo를 삭제해도 검증 통과 후 렌더러에서 TypeError.
- 분류 스크롤이 behavior:smooth를 강제하여 CSS reduced-motion 설정보다 우선.

최종 판정은 수정 후 증거와 함께 아래에 추가합니다.

## 최종 로컬 결과

- 전체 136개 테스트 통과. 기존 105개에 회귀/통합 31개 추가.
- core 두 모듈, renderer, client menu-ui의 line/branch/function은 각각 100%. 코드 커버리지 분모 밖 검증은 별도로 기록.
- 320/390/430/768/1280px 실제 브라우저 프레임: 핵심 내용·옵션 라벨 16px, 문서 가로 넘침 없음, 조사한 노출 조작 요소 높이 ≥44px.
- 320px: 고르곤졸라 → 피자 1개; NEGRONI → 1개/분류 1가지; 빈 결과에서 복원 → 70개/캄파리 7가지. 390px 위스키 → 29개, 가로 넘침 없음.
- JS 차단 프레임: 70개 메뉴/원화 가격 노출, 작동할 수 없는 검색 UI 숨김. 원본 보기에서 실제 이미지 로딩 확인.
- 본문 ink/paper 대비 13.28:1, muted/paper 5.18:1. 아트워크 영역 보조 텍스트 대비 4.58:1. 장식 이미지의 모든 픽셀 대비를 수치 검증한 주장은 아님.
- npm audit 조회 시점 의존성 경고 0건. 보안 완전성이나 플랫폼 내부 검증을 뜻하지 않음.
- 원본 6장 복사본은 업로드 바이트와 모두 동일. 메뉴 70행/가격 41개/위스키 원문·빈칸/옵션·중복을 시각 재대조. 가격·원문 데이터 파일 자체는 변경하지 않음.
- PNG, SVG 래스터, A6 PDF 래스터 모두 독립 jsQR 디코더가 같은 정식 URL 반환. PDF 105×148mm, 1페이지. 겹침/잘림 없음. 실사용 DejaVu 폰트 내장, 미사용 기본 Helvetica 리소스는 남아 있음.
- 보조 SVG 변환 도구 부재는 제품 결함이 아니며 설치된 sharp로 렌더링을 수행. 내부 QA HTML은 재빌드로 제거 후 게시.
- 배포 버전/커밋/아카이브 hash는 자기참조 커밋을 만들지 않도록 별도 최종 전달 기록에 native 결과로 기록.

## 남은 확인과 판정

발견한 수정 가능 결함은 모두 조치했습니다. 기술 검토 자료 작성은 진행할 수 있습니다. 다음을 이미 검증된 사실로 작성하면 안 됩니다.

1. 완전히 쿠키가 없는 익명 휴대폰의 공개 접속. public 설정과 연결된 Chrome 동작은 확인했으나 동일한 증거가 아닙니다.
2. 실물 인쇄물/카메라, iOS·Android 실기기, 모든 브라우저·확대·보조공학 환경.
3. 위스키 만원 단위 및 발베니 중복의 소유자 확정. 미확인 가격은 직원 문의로 유지하며 누락 금액도 추정하지 않습니다.
4. 파일 시스템/전원 장애 전부에 대한 무중단·원자성. 검증한 복구는 교체 rename 실패이며, 복구 자체 실패 시 백업 보존을 위한 구조입니다.

원격 코드 실행·로그인·결제·주문·개인정보 저장 기능은 이번 제품에 없습니다. 이를 검토 범위에 있는 기능처럼 서류에 적지 않습니다. 이번 결과는 본인의 셀프리뷰이며 새로운 독립 제3자 검토라고 쓰지 않습니다.
